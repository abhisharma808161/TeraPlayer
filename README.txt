TERA PLAYER - bina server ke (sirf APK)

STEP 1: APK build (GitHub, free)
 - github.com par naya repository banao.
 - Is zip ke andar ka sab kuch upload karo.
   Dhyan: ".github/workflows/build.yml" hidden folder hai. Agar Actions tab me "Build APK" na dikhe to
   "Add file > Create new file" me naam likho  .github/workflows/build.yml  aur file ka content paste karo.
 - Actions tab > "Build APK" run hone do (3-5 min) > Artifacts > TeraPlayer-apk download.
 - Zip nikalo, app-debug.apk phone me install karo.

STEP 2: ndus cookie (ek baar)
 - Laptop Chrome me terabox.com par login karo (alag/naya account behtar hai).
 - F12 > Application > Cookies > https://www.terabox.com > "ndus" ki Value copy karo.
 - Phone me bhejo (WhatsApp "Message yourself" se) aur app ke Settings box me paste karo.
 - Ye cookie password jaisi hai, kisi ko mat dena. Kuch hafton me expire ho sakti hai, tab nayi daalo.

STEP 3: Use
 - Link paste karke Play dabao, ya kisi Terabox link par tap karke "Tera Player" chuno.
 - Android 12+: Settings > Apps > Tera Player > Open by default > link add karo.
